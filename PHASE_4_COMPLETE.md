## 🚀 HOW TO USE THE SYSTEM NOW

### For Students
1. Navigate to `http://localhost:5000/login`
2. Login with student credentials
3. Click on "Student Dashboard" or go to `/student-dashboard`
4. View assessment history, progress, and recommendations
5. Use search and filter features to find specific assessments

### For Faculty
1. Navigate to `http://localhost:5000/login`
2. Login with faculty credentials
3. Click on "Faculty Dashboard" or go to `/faculty-dashboard`
4. View student roster with search and filtering
5. Click on students to view their progress
6. Export class data to CSV using the export button
