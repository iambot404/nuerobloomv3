# SUPABASE MIGRATION — DEBUG, FIX & FULL VERIFICATION

The MySQL → Supabase migration has already been implemented, but the project currently has errors.

**Do NOT redo the migration from scratch.**

Your task now is to **systematically diagnose, fix, and verify every issue caused by or exposed by the migration.**

I do not know all of the project's functionality, so discover it from the existing codebase.

---

Start by running the complete project using its existing setup.

Run:

* Backend
* Frontend

# 2. FIND THE ROOT CAUSE

For every error:

1. Reproduce it.
2. Read the complete error/stack trace.
3. Locate the responsible code.
4. Determine the root cause.
5. Fix the underlying issue.
6. Run the affected functionality again.
7. Confirm the error is actually gone.

Do NOT simply suppress errors or add broad try/catch blocks.

Do NOT change unrelated functionality just to make an error disappear.
