# Redesign DocHub — Premium AI Education Platform

Redesign my existing **DocHub** web application with a premium, futuristic visual language inspired by the design philosophy of **Google Antigravity**.

Reference for design inspiration:
https://antigravity.google/

**Important:** Do NOT copy Google's branding, logos, text, exact layouts, or proprietary assets. Use the site only as visual/design inspiration.

## 1. Product

DocHub is an AI-powered educational assessment platform.

It allows:

* Students to take assessments
* AI-assisted screening for learning difficulties
* Faculty to monitor students
* Faculty to view assessment results
* Students to view their results
* Visual/cognitive assessments
* Dyslexia screening
* Dysgraphia screening
* Color-vision screening
* Future support for additional learning assessments

The website should feel like a combination of:

**AI laboratory + modern education platform + premium developer product.**

It must NOT look like a generic school management system.

---

# 2. Overall Design Direction

Create a highly polished, modern interface with:

* Dark-first design
* Large typography
* Huge amounts of whitespace
* Minimal navigation
* Subtle gradients
* Soft glow effects
* Thin borders
* Glass-like surfaces used sparingly
* Large rounded containers
* Smooth animations
* Scroll-based transitions
* Floating UI elements
* Interactive cards
* Editorial-style layouts
* Strong visual hierarchy

The design should feel:

**intelligent, futuristic, trustworthy, calm, and premium.**

Avoid:

* Generic Bootstrap styling
* Excessive gradients
* Excessive glassmorphism
* Cartoonish education graphics
* Stock photos
* Excessive icons
* Dense dashboards
* Bright childish colors

Whenever DocHub is showing AI functionality, use a consistent visual language.

---

# 15. Animations

Use modern web animation techniques.

Recommended:

Framer Motion

GSAP where necessary

CSS transitions

Intersection Observer for scroll reveals

Animations should include:

* fade + translate
* scale
* blur-to-sharp
* subtle parallax
* card hover
* number counters
* progress animations
* SVG line animations

Use spring-like motion where appropriate.

Avoid:

* excessive bouncing
* spinning loaders
* random animations
* animation on every element

Performance is extremely important.

Respect:

prefers-reduced-motion.

---

# 16. Page Transitions

Navigation between pages should feel smooth.

Use subtle:

fade

slide

scale

transitions.

Do not make transitions slow.

Target approximately 200–500ms for UI transitions.

---

# 17. Cards

Cards should have:

* 1px subtle border
* 16–24px radius
* dark surface
* subtle shadow
* generous padding

On hover:

* border becomes slightly brighter
* card moves upward 2–4px
* background subtly changes
* accent glow appears

# 20. Accessibility

Follow accessibility best practices.

Include:

* semantic HTML
* keyboard navigation
* visible focus states
* sufficient contrast
* ARIA labels where required
* reduced motion support
* accessible forms
* accessible charts
* screen-reader friendly navigation

Understand:

* current routes

* assessment logic
